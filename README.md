# Инструкция по запуску

**1. Установите зависимости**
Откройте терминал в корне проекта и выполните команду:
```bash
npm install
```
*(или `yarn install`)*

**2. Запустите режим разработки**
```bash
npm run dev
```
*(или `yarn dev`)*
После этого перейдите по ссылке, которая появится в терминале (обычно `http://localhost:5173`)
